## 保留原 Scale

沿用 `Dynamic_kine_reference.m` 的操作顺序：在 LMT 时间点插值 IK，做五点 Gaussian 平滑，再对**整条原始记录**做 0.5–1.4 的 min–max Scale。分割动作后不再次缩放。因此某个片段的最小值不一定是 0.5。

Python 的五点核与 MATLAB `smoothdata(x,'gaussian',5)` 做了直接对照，检查向量上的最大差为 `2.22e-16`。没有为了得到 W 而反转 240723 的 reference。插入的等待参考是 1.5 rad、20 N·m，并在图中使用点线，与实验动作参考区分；它们不是新的站立测量。

## MAP 如何训练

采用原项目的结构：**四个非负协同成分 → 每个成分三个 Gaussian 基元 → 负载和动作速率的二次权重回归**。用训练动作的六组背肌 activation 学习基元和权重；腹部输入保留现有因果回归模块，只以训练 activation 作标签。

速率协变量取 `60 / 有效动作窗口秒数`。这是由活动窗口得到的速率代理，不能冒充原实验节拍器的 BPM；原始速度代码仍单独保留，未知速度记为未知。MAP 运行需要给定动作开始和相位时间，是任务阶段驱动的 activation 生成器。

二次回归在训练域外可能产生过高的 activation，尤其是把残缺动作误当成更快的完整动作时。因此负载和速率协变量先限制在训练域内，再计算权重。训练输入已逐样本核对保持不变。残缺片段和域外预测都保留标记，保护不等于已证明域外泛化。

## BSE/Hill 如何个体化

每个 activation 来源使用相同的 32 个力学/肌肉参数和 10 个神经控制参数。32 个参数都可参与有界优化，包括 M、L、负载力臂、偏角、肌肉容量、几何、激活时常、关节阻尼和 soft boundary。两来源共享躯干/负载几何及边界参数；其余参数可不同。**每个来源的一套固定参数用于该目录全部工况**，没有逐工况重调。

M 是模型中的有效躯干质量，不是重新测出的受试者体重。参数存在相关性，部分会接近优化范围边缘；拟合值不能当作独立测量的解剖参数。边界未被触发时，其刚度也不能从这些轨迹可靠识别。

同一隐式求解器联立推进肌纤维、肌腱和平衡关系：

\[
F_T=(F_{CE}+F_{PE}+F_{damp})\cos\alpha,
\qquad \tau_{muscle}=\tau_{back}-\tau_{abdomen},
\]
\[
I\ddot\theta=\tau_{muscle}+\tau_{exo}
-MgL\cos\theta-mgL_2\cos(\theta-\phi)-B\dot\theta+\tau_{soft}.
\]

角度与力矩来自这套耦合 Hill 系统，没有另一个角度拟合器，也不把 reference 输入在线模型。模型中的回正反馈先变成肌肉 excitation，再通过 Hill 产生力矩；不直接给关节加一项额外 PD 力矩。其神经反馈和辅助响应仍是建模假设，并非已经验证的人体控制规律。

校准主要考虑角度形状、松弛的弯腰深度、力矩误差、适度共同收缩和等待收敛。240719 的 10 kg、240723 的角度不参与角度目标；它们的力矩和 activation 仍可用于相应训练。腹部/背部的限制是公开的工程先验，不代表研究已经证明存在一个所有人通用的真实比例。

240725 在单动作拟合后出现连续状态失稳，因此增加连续训练、站立扰动恢复及阻尼/制动余量。240723 的模型还要面对动作中速度扰动，避免只在无辅助的单条轨迹上稳定。所有改动均在相同模型结构内调整参数与训练目标。

这两组的稳健校准允许优化的下界为：关节阻尼 2 N·m·s/rad、腹肌容量尺度 100 N·m、负向肌肉请求限幅 10 N·m。容量尺度不是实际施加的恒定力矩。240723 的神经反馈混合比例在 0.9–1 之间优化，也不代表 90% MVC；这些是明确的稳定性先验，实际输出仍通过 Hill 力学计算。

## MPC 与验证

MPC 每 20 ms 更新，预测 0.4 s，使用四个控制块。实际状态内部以 1 ms 推进，辅助硬件上限为 80 N·m、变化率为 200 N·m/s。背肌 5/10/15 kg 的 100/140/180 N·m 是**软目标**；不能把它们解释为实际肌肉力矩的硬截断。各目录使用自己的候选权重和裕量，结果 JSON 记录最终设置。

在线目标角度来自同一模型的无辅助预测。MPC 看不到实验 reference。动作结束后不立即撤掉辅助，而是用当前角度、角速度、接触负载和运动意图决定回正辅助及退出。可选的角度 command governor 也只预测同一 Hill 系统并减少正向辅助，不裁剪实际 θ；它本身不能保证对所有输入都稳定，所以仍检查完整连续回放。

动作之间不重置角度、角速度、激活或肌腱状态。缺少负载时只串联实际存在的负载，不生成一条虚构的 10 kg/15 kg reference。主连续图按记录完整性选片段，标出 train/test；各工况图和逐动作表仍保留留出片段及其问题。

验证包括：固定参数哈希、原 reference 保持不变、零辅助一致性、辅助幅值/变化率、半步长对照、站立扰动后的 30 s 收敛。另把 reference 改成任意曲线，检查在线输出保持完全相同。数值检查通过不等于实验拟合通过，详见每组 `validation.json` 与图表。

留出片段未直接进入参数最小二乘目标，但本轮开发查看了其结果并据此修正稳定性与输入保护，因而应称为**留出记录的开发验证**，不能当作最终封存的独立测试。尚无独立辅助实验来验证“辅助力矩抵消人体肌肉请求”的假设。

同一文件内的片段还共享原项目对整条记录的 Scale 和处理流程，不等于独立采集记录。目前 240719 的 MAP 留出角度趋势仍不好；240725 虽保留主要弯腰形状，部分谷值仍偏浅。240723 的 θ reference 待核实后才能评估角度准确性。不能把数值稳定、背肌占主导与实验拟合准确混为一项结论。

软力矩目标也没有全部消除短时超出：逐动作最差超出约为 240617：16.44、240627：5.61、240719：37.91 N·m，后者峰值时辅助已达 80 N·m。240723、240725 的本次目标未超出。结果表保留所有超出，不通过裁切曲线掩盖；整个回放的执行器幅值/变化率均合规。合计 3 次 QP 候选被拒绝后采用有界回退。

## 运行

在项目根目录的 MATLAB 中：

```matlab
demo_hill_subjects            % 查看已经生成的结果，不重新训练
demo_hill_subjects('replay')  % 使用保存的模型/MPC 参数重新回放
demo_hill_subjects('train')   % 从数据重新训练 MAP、BSE，并调参/验证 MPC
```

原 subject：`demo_hill_mpc_plots(false)` 查看结果，`demo_hill_mpc` 重新运行。

回放/训练需要 Python 的 NumPy、SciPy、Matplotlib，以及 GCC。Python 入口是 `experiments/multi_subject/run_subjects.py`；依赖见该目录 `requirements.txt`。可设置 `EXO_PYTHON` 指定 Python、`HILL_GCC` 指定编译器。

默认数据位于原项目的 `YOUHAN LI code and project description/Data`。迁移后可在 MATLAB 设置：

```matlab
setenv('EXO_SUBJECT_DATA_ROOT', 'D:\your-data\Data');
```

训练耗时明显长于只查看图片。原始记录和生成的中间结果留在本地；GitHub 可携带源码、文档、图和小型参数文件，不需要提交多 GB 的采集数据。
