份数表示文件夹数量，不表示独立实验数或通过质量检查的数量。240617 中间负载的目录是 `CalibrationData/dynamics_stoop_7.5kg_{23,33,43}` 和 `CalibrationData/dynamics_stoop_12.5kg_{23,33,43}`。这些后缀保留原标签，没有擅自解释成实际动作频率。

此前 `quality_gate.py` 和 `prepare_subjects.py` 都把负载限定为 `(5, 10, 15)`，遗漏了中间两个负载。当前 MAP 每组只使用了 7 段训练动作；240617 / 240627 的留出动作分别为 3 / 7 段，也只来自这三个负载。重复动作数量不能代替负载覆盖。

这不表示三个负载在数学上无法拟合一个 MAP，但现有结果不能证明完成了原五负载方案，也没有验证 7.5 / 12.5 kg 的预测表现。

## 240617 中间负载并非原始 EMG 全部缺失

逐一读取六份记录后，发现了两层不同的导出范围：

| 负载 / 目录后缀 | `Activations.sto` 时长 | `emgFilt.sto` 时长 | 当前联合处理的动作提取情况 |
|---|---:|---:|---|
| 7.5 / 23 | 8.10 s | 31.00 s | 检出动作在记录末尾仍未完成，平滑指标超出原基准范围 |
| 7.5 / 33 | 7.43 s | 25.86 s | 在短 activation 记录中未检出完整动作 |
| 7.5 / 43 | 7.05 s | 27.39 s | 动作未完成，动作邻域有约 0.72 s 断档 |
| 12.5 / 23 | 8.26 s | 32.53 s | 在短 activation 记录中未检出完整动作 |
| 12.5 / 33 | 6.32 s | 24.24 s | 检出动作在记录末尾仍未完成 |
| 12.5 / 43 | 6.73 s | 27.25 s | 检出动作在记录末尾仍未完成 |

时长按每个原生文件的首末时间戳计算，和共同时间范围内实际可用的时长略有不同。六份记录的原生 CEINMS 导出时间戳、力×力臂→力矩恒等式及 activation/EMG 时钟对应检查通过；这不能消除截断，也不能代替独立的硬件同步校验。

较长的 `emgFilt.sto` 保存了 8 个传感器通道，包括双侧腹直肌、髂肋肌、腰最长肌和胸最长肌。7.5 kg 的三份完整 filtered EMG 未发现倒退时钟或超过 250 ms 的断档；12.5 kg 每份存在一处超过 250 ms 的断档，需要按动作位置判断，不能直接丢弃整份，也不能跨缺测插值后宣称数据完整。

![完整 filtered EMG 与较短 activation 导出的时间覆盖](map_coverage_audit/full_emg_vs_activation_coverage.png)

图中的灰色范围是已有 CEINMS activation 的时间区间，红虚线为其终点；三条曲线分别为三组背部传感器的双侧均值，仅用于展示记录覆盖，没有作为新的训练结果。

`emgFilt.sto` 的传感器 EMG 和 `Activations.sto` 的模型 activation 是不同处理层级，不能直接互换并沿用原参数。当前联合筛选还使用了角度/力矩和动作完整性条件；某段不满足联合 BSE 数据要求，也不自动意味着其全部 EMG 都不能用于单独的 MAP 分析。

## 现阶段的结论

- **240617：五个负载的原始记录均存在，是继续恢复完整五负载 MAP 数据的候选；当前已训练 MAP 仍只覆盖三个负载。** 需要按完整 EMG 与 IK 的共同绝对时间戳核对动作相位、缺测及平滑程度，并恢复一致的 activation 处理后，再重新划分训练与留出数据。
- **240627：当前能识别的弯腰记录只有 5、10、15 kg，缺少 7.5、12.5 kg，尚不满足五负载完整训练要求。** 中间负载预测只能标为未验证，不能把模型插值当成真实训练记录。

此前 48 个动作/activation 组合的 MPC 回放结论仍仅适用于已使用的三负载动作。它们没有验证中间负载 MAP，也不代表 48 次独立实验。本次只复核数据和更正范围说明，未改变或重新训练现有 MAP、BSE、MPC。
