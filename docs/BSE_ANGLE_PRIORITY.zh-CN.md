## 输入是如何配对的

从三个 `Combination_raw.mat` 取第 2 列作为实验来源 activation，
从对应 MAP `Combination_*.mat` 取第 2 列作为模型生成 activation。
程序逐点断言：两份数据的 theta reference 完全一致，torque reference 也完全一致。
九段负载/速度组合、时间网格、初始角度、接触窗口都相同。每 10 点取样，步长 0.01 s。

这里的“实验来源 activation”是项目已有处理流程产生的 activation，
不是未经处理的双极原始 EMG，也不是直接测得的肌肉激活真值。
MAP 的这列同样是生成的 activation，不应把两列画成原始 EMG 电压。
上游实验处理包含插值、加权及平滑；上游 MAP 参数也曾使用这些工况。
因此本结果验证下游角度模型，不是独立受试者或原始 EMG 到角度的端到端泛化证明。

## 为什么旧角度可能失控

检查 `general_model_op_scale/Torque_function_constant.m` 后，发现该版本 Ki=0，
因此不能把失控直接归因于 PID 积分项累积。需要重点关注的是：

1. 低阻尼、强非线性肌腱刚度和数值积分的组合。
2. 每步仅少量固定点迭代，没有严格的收敛残差检查。
3. 原角度墙是有限力矩的软限位，不能从数学上保证角度永远处于范围内。
4. 某些分支使用 reference 反馈；拟合图不能直接等同于独立前向预测。

## 新方程：有界阻抗降阶候选模型

这次增加的是一个独立候选模型，不是宣称已经修复并验证了原 Hill 肌肉—肌腱模型。
两种输入均调用同一个 `angle_rollout.m`；没有按来源切换方程的分支。
只分别拟合特征标准化参数和回归系数，不为每段单独拟合参数。

先从 activation 构造因果记忆特征：0.04 s 预滤波、0.10/0.40 s 记忆、
记忆差、三阶 activation 项、已知负载交互项；接触上下文另经 0.20 s 因果平滑。
接触区间来自原项目工况元数据，实际使用时必须提供相应负载/接触信息。
模型不使用速度标签、时间相位、未来参考角度，也没有预先写入 W 形模板。

令 z 为标准化特征的线性组合，角度平衡点为：

`u = qmax / (1 + exp(-z))`，其中 `qmax = 95*pi/180`。

再用相同的临界阻尼系统：

```text
ds/dt     = (u - s)/h
dtheta/dt = (s - theta)/h
h = 0.15 s
```

等价二阶方程是 `theta_ddot + 2/h*theta_dot + theta/h^2 = u/h^2`。
初值 `s(0)=theta(0)=第一帧参考角度`，因此初速度为 0。
除这一帧之外，预测函数根本不接收 reference。
部署时应由初始角度传感器给出该值，不能用本实验的首帧替代真实初始化。

使用精确零阶保持离散化。离散状态矩阵及输入权重非负，每行权重之和为 1。
因此，当初始角度在范围内、输入有限时，状态始终是有界量的凸组合，
角度保持在 `[0,95°]`；不是积分完以后把异常角度截断。
恒定平衡点下不会产生欠阻尼自由振荡。随输入变化仍可能出现多个谷，
“不会疯转”不等于“必然拟合成正确 W 形”。
95° 是沿用项目限位的工程设定；reference 上游还做过角度归一化，
不能据此宣称这是经解剖或临床验证的关节安全活动范围。

力矩从同一条预测角度计算，不另行训练一条独立力矩回归曲线：

```text
I = m*L2^2 + 4*M*L1^2/3
torque = I*theta_ddot + B*theta_dot
         + g*M*L1*cos(theta) + g*m*L2*cos(theta-phi)
```

沿用原项目 M=22.6006、L1=0.345、L2=0.760606、phi=0.936847；B=0.5。
这是分段负载假设下，维持该轨迹所需的净驱动力矩；不是经过 Hill 力长/力速关系
验证的单根肌肉张力，也没有实现肌肉力量上限或真实接触冲击。
本方法增加了角度稳定性约束，但不能把角度有界等同于完整生理可行性。

## 如何优先拟合 W 形

每段损失按样本数归一化，避免长片段支配优化。损失包含：

- 角度误差，以 0.15 rad 为尺度。
- 角速度误差，以 0.5 rad/s 为尺度，残差权重 0.5。
- 训练集峰谷和端点处的角度误差，残差权重 0.8。
- 力矩误差，以 100 Nm 为尺度，残差权重仅 0.15。
- 回归系数正则化，残差权重 0.025。

以上权重作用于残差，`lsqnonlin` 最小化它们的平方和。
训练时可以用参考角度求导、找峰谷；预测时不使用这些量。
三次留组验证各排除速度 35、45、55 的全部三种负载，再用其余六段拟合。
这是一轮探索性条件留出评估：开发时看过这些工况的曲线，尚需新的锁定测试集。

`Wmatched` 的判据是参考和预测各恰有两个明显谷：突出度至少 0.12 rad，间隔至少 0.5 s。
该指标只检查双谷数量，不能替代幅值和时间误差。只有满足双谷判据时才计算两个谷及
谷间中央峰的配对误差；失败时写 NaN，不强行匹配并掩盖多余的谷。

## 本轮实际结果

整组速度留出、九段等权平均：

| 输入 | 角度 RMSE | 形状相关系数 | 力矩 RMSE | 双谷数量匹配 |
|---|---:|---:|---:|---:|
| 实验来源 activation | 0.1675 rad / 9.60° | 0.811 | 50.69 Nm | 5/9 |
| MAP activation | 0.1721 rad / 9.86° | 0.810 | 42.97 Nm | 8/9 |

实验输入的预测角度范围为 29.59°–84.71°，MAP 输入为 23.13°–80.50°。
逐段最小值误差均值分别为 4.09°、4.62°；最大值误差均值为 2.15°、2.76°。
这些幅值指标不代表峰谷发生时间也完全一致，时间误差另见 CSV。

全九段标定后的角度 RMSE 分别为 0.1456 和 0.1398 rad，双谷匹配均为 8/9。
标定效果不能当作泛化效果。旧归档 BSE（MAP 输入）的平均角度 RMSE 为约 0.4441 rad，
力矩约 27.95 Nm；前一版降阶模型分别约 0.2226 rad、27.22 Nm。
本轮 MAP 角度误差进一步下降，但力矩误差明显增加，不能说只是无代价的小幅牺牲。

留出时，实验输入在 15kg/35、15kg/45、5kg/45、15kg/55 仍多出一个明显谷；
MAP 输入在 15kg/35 仍多出一个谷。当前解决了角度无界漂移，改善了主趋势，
但尚未达到全部工况峰谷都接近的目标。不要把这一版当成已经完成验证的最终控制模型。

下一步应优先补充重复试次，验证相同 activation 是否对应不同运动阶段；
若是，仅靠 activation 与负载无法唯一确定角度，需要拮抗肌、初始状态或角度传感器信息。
保留本版稳定角度子系统，再加入受约束的肌肉力长/力速关系和力量上限，
联合检查角度、力矩和肌肉力的可行性；不能只恢复独立 torque 回归来掩盖动力学不一致。
