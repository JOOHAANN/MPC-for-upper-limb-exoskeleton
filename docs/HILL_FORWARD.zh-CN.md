## 计算链与假设

本模型从 activation 计算 Hill 力，由同一份力矩驱动关节积分：

```text
activation + 当前肌纤维长度/速度
  -> Hill 主动力 + 并联被动弹性力
  -> 肌腱传递力 Ft -> 肌肉力矩 R*Ft
  -> 关节角加速度 -> 数值积分 theta 和 theta_dot
  -> 更新肌肉几何，进入下一步
```

没有角度目标 u，没有人为指定的 W 形，没有 reference PD，没有边界弹簧，
没有从预测角度逆算并冒充肌肉输出的 torque。拟合损失可使用参考，但预测函数不接收参考轨迹。

这是**刚性肌腱 Hill 近似**，保留主动收缩元件、并联被动弹性、力长、力速和羽状角。
没有声称已经修复并验证原来的弹性肌腱状态方程；也没有证明本项目肌腱足够短/硬，可以忽略顺应性。
选择这一近似，是为了先隔离原高阶肌腱刚度函数和刚性积分的影响。
刚性肌腱与弹性肌腱是文献中区分的模型假设；它们的准确性与计算性质并不相同，
参见 [Millard 等，2013](https://pmc.ncbi.nlm.nih.gov/articles/PMC3705831/)。
本实现的曲线是明确写出的简化 Hill 型曲线，不是 OpenSim/Millard 实现的逐项复刻。

## 具体方程

定义固定肌纤维厚度 `w = lo*sin(alpha0)`，`alpha0=0.24086 rad`。
以固定姿态 `qref=1.4 rad` 定义归一化肌纤维长度参数 `lref`：

```text
x(q) = lo*sqrt(lref^2-sin(alpha0)^2) - R*(q-qref)
lm   = sqrt(x^2+w^2)
cos(alpha) = x/lm
vm   = -R*qdot*cos(alpha)
ln   = lm/lo
vn   = vm/(vmax*lo)
```

这里 `qref` 仅为几何坐标的固定基准，不是希望 theta 追踪的角度；没有任何跟踪 qref 的控制项。
肌肉总长度满足 `dLmt/dq=-R`，肌腱刚性时其长度不变，因此不需要单独积分肌腱长度或肌肉总长度。
这使长度和角度通过几何严格关联，避免独立积分带来的几何漂移。

```text
fl(ln) = exp(-((ln-1)/0.45)^2)

fv(vn) = max(0,1+vn)/(1-vn/0.25)                 [vn <= 0]
       = (1+1.5*vn/0.25)/(1+vn/0.25)              [vn > 0]

fp(ln) = max(0, (exp(5*(ln-1)/0.6)-1)/(exp(5)-1))

a_eff = clip(a,0,1)^gamma
F_CE  = F0*a_eff*fl*fv
F_PE  = F0*fp
Ft    = (F_CE+F_PE)*cos(alpha)
torque = R*Ft
```

`gamma` 是两种 activation 的幅值标定参数，不用于预测目标角度。
原始两列本身都是经过上游处理的 activation，不能视为独立生理激活真值。
被动弹性位于肌肉内部，有明确的肌纤维长度依赖，不是额外的关节限位弹簧。
但是如果拟合大量依赖 F_PE，也必须警惕参数在用被动力补偿模型缺失，不能自动解释为真实组织特性。

最后积分唯一的关节力学方程：

```text
I = m*L2^2 + 4*M*L1^2/3
qddot = [R*Ft - M*g*L1*cos(q) - m*g*L2*cos(q-phi) - B*qdot]/I
```

固定 `M=22.6006, L1=0.345, L2=0.760606, phi=0.936847`。
`B` 为有限范围内标定的被动黏性阻尼，不是参考反馈项。
外载荷采用原工况接触窗口，并用 80 ms 因果一阶滤波表示逐步载荷转移；
这是有效负载假设，不是实测接触力，也没有完整建模抓取冲击和变质量动量交换。

采用 RK4，每个 0.01 s 数据间隔包含两个 0.005 s 积分步。
每个 RK 子步重新计算肌肉几何、力长/力速和关节加速度；不是只计算一次肌肉力再反复积分。
初始角度来自第一帧，初始角速度由第一帧与**预测开始前**的帧计算；不读未来角度。
没有角度裁剪或保证角度范围的人工状态方程；越界会被记录，不能靠裁剪隐藏。

## 参数标定与可辨识性

在这个刚性肌腱单关节模型中，`F0*R` 和 `R/lo` 比各自分开的 F0、R、lo 更直接可辨识。
因此固定 `R=0.03285315745 m`（原归档值），优化六个参数组合，避免三者互相抵消：

| 参数 | 标定范围 |
|---|---|
| F0*R | 40–550 Nm |
| R/lo | 0.06–1.1 |
| lref | 0.75–1.3 |
| B | 0–8 Nm·s/rad |
| vmax | 1–10 最优肌纤维长度/秒 |
| gamma | 0.5–2 |

两种输入采用相同模型、范围和目标函数。没有每段单独的参数，也没有时间相位特征。
先筛查 180 个确定随机种子的初值，再从六个候选起点进行有边界最小二乘标定。
损失以角度为主，同时考虑斜率、训练峰谷、力矩误差、力矩变化率、角度越界和被动力过大的软惩罚。
范围惩罚仅影响训练参数，不会在预测时生成任何外部力矩。

分别保留全数据标定与按速度 35/45/55 整组留出的结果。
这仍是开发阶段评估：上游 MAP、数据处理和模型开发已接触这些工况，不能当作锁定的独立测试集。
参考 theta 上游做过归一化，质量和几何参数也未经本轮独立测量；这些限制直接影响物理解释。

## 本轮结果：没有达到最终拟合目标

整组速度留出、九段等权平均：

| 输入 | theta RMSE | torque RMSE | 平均形状相关系数 |
|---|---:|---:|---:|
| 实验来源 activation | 0.3153 rad / 18.06° | 67.32 Nm | -0.177 |
| MAP activation | 0.3195 rad / 18.31° | 51.74 Nm | 0.272 |

实验输入预测范围为 39.53°–79.36°，但曲线过于平坦，不能认为已复现正确 W 形。
其被动肌肉力矩的时间积分占总肌肉力矩的比例，逐段平均约 93.2%，明显提示模型补偿问题。
MAP 输入的同一指标约 24.2%，但 10kg/35 的角度最高达到 **155.77°**，
15kg/55 也略超过 95°。没有截断这些角度，也没有补回隐藏的边界弹簧。

单看“双谷数量”，两种输入分别有 6/9、8/9 段匹配；但与上面的相关性、幅值和越界结果合看，
显然不能将这个计数当作拟合成功。这是本轮一个明确的反例。

积分步长从 0.005 s 减半到 0.0025 s，18 段留出预测中最大的角度差仅
**0.000597 rad（0.0342°）**，力矩差 **0.0283 Nm**。
因此本实现的主要拟合偏差及该次越界，不能用积分步长误差解释；
更需要检查单肌肉结构、参数可辨识性、初始状态和上游归一化参考的物理一致性。
这项结论仅针对本版数值测试，不是证明原弹性肌腱积分不存在问题。

参考一致性检查中，固定关节参数下，B=0 时各段参考力矩与参考角度所需力矩的
RMSE 约 27–47 Nm。这不能单独证明数据错误，但说明两项参考在当前机械假设下不完全相容。

还尝试过从另一种输入的同训练集参数初始化再优化。训练损失有所下降，但产生新的留出失败，
没有采用，也没有用角度 surrogate 兜底；见 [失败记录](hill_forward_refinement_failure.md)。
基线保留决定参考过开发工况结果，因此更不能把本轮数字称为独立泛化证明。

下一步应优先恢复/核对未归一化的真实角度、身体与负载几何及初始状态，再检查是否缺少
拮抗肌或其他真实力矩来源；随后验证弹性肌腱 Hill 的顺应性。
不应通过虚构角度目标、增加未说明的恢复力，或单独拟合 torque 来掩盖这些缺口。
