# 边界力矩与 torque 波动诊断

运行 `demo_bse_torque_breakdown`。需先有 `demo_bse_angle_priority` 生成的结果。
本脚本不重新标定、不更改方程；重放旧 BSE，并分解新模型保存的留组预测。
输出在 `results/bse_torque_breakdown/`，包括三种速度的 PNG/PDF、可交互 FIG、逐点 CSV 和汇总。

## 旧 BSE 的边界设置

实际检查并重放的版本：`general_model_op_scale`。
原 `Torque_function_constant.m` 中设置：

| 参数 | 值 |
|---|---:|
| 下限 / 上限 | 0° / 95° |
| k_wall | 1200 Nm/rad |
| Fmax（变量名虽叫 F，实际用于力矩） | 900 Nm |
| c_wall | 0 Nm·s/rad |
| tanh 激活过渡系数 a | 30 rad⁻¹ |

这是原代码已有设置，本轮没有将它调大。在范围内部边界力矩为零；越过上限后为负，
越过下限后为正，均指向范围内部。900 Nm 是渐近饱和值，不是每次接触都施加 900 Nm。
由于激活门函数存在，1200 是刚度参数，不是边界处的精确切线刚度。

诊断图使用原函数第 6 列输出的边界力矩，并逐点验证与原静态限位公式一致。
它在原代码中记录当前已接受状态的值；内部固定点迭代会在各自预测状态上另行求同一公式。
九段轨迹按 100 Hz 对齐后，边界力矩绝对峰值最大约 632 Nm。
例如 15kg/45 为约 471 Nm，15kg/55 为约 632 Nm。
这些边界力矩足以明显影响角度，不是可以忽略的小扰动。

旧 BSE 图中的 torque 是肌腱力乘力臂，不是所有力矩的和。
边界力矩参与旧 BSE 的动力学，间接影响角度及肌腱状态；不要直接把边界曲线加到旧输出上。
旧模型另有低 activation 时的参考角度 PD 平衡项，逐点 CSV 也导出了该项。

## 新 demo 的边界力矩为零，但仍有内部恢复作用

新模型没有边界弹簧，所有时刻的边界力矩均为 0 Nm。
不过它采用平衡点动力学，不能因此声称模型没有虚拟恢复作用。

```text
theta_ddot = (u - theta)/h^2 - 2*theta_dot/h
h = 0.15 s
```

乘惯量 I 后，可以拆成：

```text
虚拟平衡点恢复项 = I*(u-theta)/h^2
动态阻尼项       = -2*I*theta_dot/h
两者之和         = I*theta_ddot
```

相应等效刚度为 `I/h^2`，当前 0–15 kg 接触负载下约 **159–545 Nm/rad**；
等效动态阻尼为 `2*I/h`，约 **48–164 Nm·s/rad**。
这些是降阶角度动力学的内部虚拟阻抗，不是人体边界接触力，也不是实测肌肉刚度。
两个分量可能各自较大、相互抵消，已单独绘制 `virtual_impedance_speed*.png/pdf`。
例如 15kg/45 的实验输入中，恢复项绝对峰值约 446 Nm，动态阻尼项约 390 Nm。
它们的和已包含于惯性项，不能再次加入总 torque，否则会重复计算。

新模型输出的力矩分解为：

```text
torque = I*theta_ddot + B*theta_dot + 身体重力项 + 负载重力项
B = 0.5 Nm·s/rad
```

其中 B 是逆动力学中的被动黏性阻尼，和上面的动态阻尼不是同一参数。
加速度直接使用模型解析表达式，不是对绘图角度进行两次数值差分。
程序逐点检查各分量之和等于保存的 torque，也检查内部阻抗两项之和等于惯性项。

以 **15kg、速度45、实验 activation** 为例：惯性项绝对峰值约 **215 Nm**，
被动阻尼项约 **1.19 Nm**，身体重力项约 **66.5 Nm**，负载重力项约 **111.9 Nm**，
最终 torque 峰值约 **379 Nm**。各分量峰值发生时间不同，不能直接把这些峰值相加。
图中可见快速起伏主要来自惯性项；负载接触采用阶跃，也给重力和惯量带来跳变。

因此，当前 torque 的不平滑不能归因于新模型的边界弹簧；原因在于角度轨迹的曲率、
平衡点驱动以及理想化的负载接触切换。角度数值有界并没有自动保证力矩可实现。
接下来应在动力学内部联合约束加速度/力矩及其变化率，并使用合理的负载转移过程，
而不是只平滑最终 torque 曲线或继续加大边界弹簧。
