## 沿用的方法

MAP 保留四个非负协同、每个协同三个 Gaussian 基元，以及负载/节律二次特征的权重回归。只用训练工况拟合；合并背肌权重从合格的训练几何冻结。MAP 输入为负载和动作节律，不读取待验证的 reference 角度或力矩。

BSE 使用同一套带肌腱柔顺性的 Hill 背/腹拮抗模型、神经输入与站立恢复方程。实验 activation 与 MAP activation 可有不同个体参数，身体/负载几何和软边界参数在两分支之间共享。M、L 和所有 32 个物理参数、10 个神经参数均有资格参与有界优化，使用两轮交替拟合及站立扰动恢复检查。原成功模型仅用于数值初始化，并非新 subject 的最终参数。

θ 和肌肉 torque 来自同一耦合模型。控制器保持其预测的无助力动作趋势，减少背部 torque 超限；reference 只用于离线训练和评分。先拟合 BSE，再冻结 BSE/MAP 调 NMPC，不用 NMPC 的助力效果反向修改 reference。

NMPC 沿用训练数据估计的预测误差余量、扭矩约束优先、接近阈值的低助力目标和动作后恢复处理。阈值沿用已有设计：5/10/15 kg 对应 100/140/180 N·m，中间负载线性插值；这些是设计目标，并非医学安全限值。执行器约束为 0–80 N·m、变化率不超过 200 N·m/s。只用训练动作选预测时域和余量，再固定控制器回放留出动作。

图中同时展示 θ、净肌肉 torque、背部/腹部各自的 torque、阈值横虚线、执行器助力和 soft-boundary torque。站立间隙的 1.5 rad/20 N·m reference 为明确标记的填充值，不是实验测量。

## 结果含义与限制

两组 MAP 的留出 activation RMSE 约为 0.0597（725）、0.0567（730）。这只是处理后激活的预测误差，不是肌肉力矩或生理有效性的独立证明。

730 的 BSE 留出净力矩 RMSE 为实验/MAP 53.1/54.9 N·m，θ 趋势相关性为 0.662/0.705。最终 NMPC 在 5 个动作 × 两种激活的 10 组回放中，保留了各自动作的主要角度谷点数；其中 5 kg 记录只有一个主要谷点，不能冒充完整 W 形或九工况验证。一个 15 kg 实验激活留出动作峰值为 180.62 N·m，比 180 N·m 目标高约 0.62 N·m，其余动作未超限；没有超过目标 1 N·m 的采样时段。助力最大约 80 N·m，实际 soft-boundary torque 为零。

控制器在训练段比较了余量系数 0.25、0.5、0.625、0.75 后固定为 0.75。增大到 0.625 时，15 kg 的助力已接近 80 N·m，峰值仍有约 1.6 N·m 超限；不能把这种执行器饱和解释为单纯“权重不够激进”。最终训练段无超限，但轻负载也有额外余量，5 kg 峰值约 84.8/89.1 N·m。没有依据留出动作的结果再修改参数，因而保留并报告小幅留出超限；控制器不是对未来未知输入的绝对约束保证。

两组 Exp 的默认 `Torque.sto` 是 A=0.1 下、沿原导出等价 active-only 规则重算的 CEINMS 模型估计。没有独立逆动力学或测力数据，不能称为已校准的真实力矩。BSE 对它的拟合属于模型间的一致性检查，不能独立证明 Fmax、背腹发力比例或绝对扭矩正确。

三段 BSE 训练动作不足以唯一辨识全部自由参数；使用了原模型初始化、参数界限和先验。软边界未被充分激发时，其参数尤其无法从现有数据唯一确定。MPC 的 reference 扰动测试、数值步长检查及静立恢复检查通过，也不等于硬件实时或跨受试者验证。

输入包含离线居中的 300 ms Gaussian 平滑；实机需换用因果处理或计入缓存延迟。当前是 MATLAB 查看/启动、Python 训练与控制、C 物理内核的离线仿真链路，未改写或运行旧 Simulink `.slx`。

## 查看与继续

MATLAB 切换到 `GitHub_Ready`，运行：

```matlab
demo_exp_subjects          % 查看保存的图
demo_exp_subjects('status') % 仅检查完成状态
demo_exp_subjects('run')   % 仅执行缺少的训练/控制阶段
```

直接调用已经训练好的 MAP activation 预测器：

```matlab
p = predict_exp_activation('240730Exp_A01', 10, 9);
plot(p.timeSeconds, p.backActivation);
xlabel('Time (s)'); ylabel('Predicted activation');
```

三个输入依次为 subject、负载 kg、完整动作频率 BPM，也可传第四个自定义动作时间向量。它只读取训练得到的 MAP 参数，不读取该动作的实验 EMG、θ 或 torque；输出六个背肌通道和合并 activation。文件名中的 25/35/45 等是速度代码，不能直接当作完整动作 BPM。超出训练协变量范围时按原 MAP 规则限制到训练域并在返回结构中标记；这不能作为域外有效性的证明。

背部使用上述 NMF/Gaussian MAP 预测器，MAP 分支的腹部输入沿用既有、仅由训练激活学习的因果辅助生成器；腹部没有冒充独立的 NMF 预测或实测值。`predict_exp_activation` 导出背部 MAP 输入，后续肌肉实际激活仍由 BSE 的神经/肌肉动力学计算。
